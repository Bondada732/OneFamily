2. Multi-Tenancy & Security Architecture

Multi-Tenant Isolation Guarantee: Every entity table references family_id with ON DELETE CASCADE referencing families(id). This partitions all financial, medical, and document records by household and guarantees complete data isolation.
Role-Based Access Control (RBAC) Hierarchy
Role Administrative Scope Feature Access Permissions
FAMILY_HEAD Full Super-Admin Manage family billing, invite/remove members, grant permissions, view full finances & vault
SPOUSE Co-Administrator Full financial tracking, health profile management, vault access, family calendar & tasks
ADULT Standard Member Log personal expenses, view household schedules, grocery checklists, chore tasks
CHILD Restricted Member Assigned chores, savings goals/allowance tracking, personal school calendar
VIEWER Read-Only Guest View shared family memories, selected calendar events, emergency contacts

5. Helpful SQL & API Query Cheat Sheet

1. Query all active family members by User Email
SELECT 
    u.id AS member_id,
    u.name,
    u.email,
    u.role,
    u.relationship,
    f.name AS family_name,
    f.family_key
FROM users u
JOIN families f ON u.family_id = f.id
WHERE u.family_id = (
    SELECT family_id FROM users WHERE email = 'rambabub789@gmail.com' LIMIT 1
)
ORDER BY 
    CASE 
        WHEN u.role = 'FAMILY_HEAD' THEN 1
        WHEN u.role = 'SPOUSE' THEN 2
        ELSE 3
    END;
2. Category-wise Monthly Expense Breakdown
SELECT 
    category_name,
    COUNT(*) AS transaction_count,
    SUM(amount) AS total_spent
FROM expenses
WHERE family_id = 'fam_1789400030588'
  AND date LIKE '2026-09%'
GROUP BY category_name
ORDER BY total_spent DESC;
3. Member Emergency Medical Cards
SELECT 
    ep.full_name,
    ep.blood_group,
    ep.allergies,
